# Citing pyHelioFITS

Cite the version you used. [`CITATION.cff`](https://github.com/GillySpace27/pyHelioFITS/blob/main/CITATION.cff)
in the repository gives the author and version, and GitHub's "Cite this repository" button reads it.

Each release is archived on Zenodo, which assigns that version its own DOI, and one concept DOI that
always points at the latest. Use the version DOI for the release you ran. The DOIs appear on the
repository's Zenodo badge once the first release has been archived; none exists before then.

Exports made with HelioFITS Studio carry their own record (`.hfrec`) that names the Core commit and the
data that produced them. To check one, see [Reproducing an export](reproduce.md).
